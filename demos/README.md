# Demos

This folder contains presentation-ready scenarios for WISENET.

## Available Demo

### stream-control-2025-10

Start/stop streaming demo showing full control loop with ESP32, MQTT, FastAPI, and InfluxDB.

- Overview and runbook: [demos/stream-control-2025-10/README.md](stream-control-2025-10/README.md)
- Message and API contracts: [demos/stream-control-2025-10/contracts.md](stream-control-2025-10/contracts.md)
- Simulator script: [demos/stream-control-2025-10/simulators/fake_device.py](stream-control-2025-10/simulators/fake_device.py)

## How To Use This Folder

1. Pick a demo folder.
2. Read its local README first.
3. Validate infrastructure health before presenting.
4. Run the scripted steps and keep contract docs open during Q&A.
